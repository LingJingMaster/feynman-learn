# 费曼学习法

Codex / agent skill：用费曼的方式把一个主题讲透。

先用给 12 岁孩子的类比解释，再标出容易混淆的地方，经过 2–3 轮追问和改写，最后用「讲给别人听」或「用到新场景」检验，并留下一张教学笔记。

## 安装

```bash
git clone https://github.com/LingJingMaster/feynman-learn.git ~/.codex/skills/feynman-learn
```

在对话里说「用费曼学习法讲透……」，或显式调用 `$feynman-learn`。

## 文件

- `SKILL.md`：技能说明
- `agents/openai.yaml`：界面名称与默认提示
